# ADR 0002：文档解析选择

## 状态

接受（M0 核心范围）

## 背景与实测

解析矩阵验证了 Markdown 与 PPTX 的正文提取，以及 PPTX 对象级来源定位；核心 3 项全部通过。
完整报告见 `docs/evaluations/m0-parser-matrix.md`，机器证据见 `artifacts/m0/parser-core.json`。

## 决策

采用“统一规范化接口 + 格式专用解析器”：MarkItDown 负责通用文本入口，PPTX 使用专用解析保留页码和对象位置。
扫描 PDF/OCR、复杂 DOCX 表格与版面、加密和损坏文件作为明确能力项逐步加入，不能把纯文本成功等同于位置保留。

## 拒绝方案

- 所有格式只走一个通用转换器：无法可靠保留对象级来源位置。
- 首版自研完整 Office/PDF 排版解析器：投入大且会推迟纵向链路。

## 后果与回滚触发

每条 Fact 必须保留文件、页码/段落/对象等可用定位；不支持的格式或能力应显式降级。
若 MarkItDown 的版本兼容性或文本保真度低于格式专用解析器，则只保留其为兜底入口。
