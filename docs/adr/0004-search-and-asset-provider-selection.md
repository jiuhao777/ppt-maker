# ADR 0004：搜索与图片素材 Provider

## 状态

契约接受，默认 Provider 待选

## 背景与实测

搜索和免费图片是重要能力，但当前没有搜索/图片 Provider Key。M0 已验证保留成功、错误、重复 URL、时延、域名
和来源/许可证信息的 Runner；官方条款核验见 `docs/evaluations/m0-search-and-assets.md`。

## 决策

搜索候选保留博查与 Tavily，图片候选保留 Pexels 与 Pixabay，获得 Key 后才用冻结中文查询实测选型。
无 Key 时联网研究失败关闭；允许用户手动给 URL。宽松素材模式必须展示原链接、作者和许可证风险并经人工确认。
网页内容先提取、净化、事实化进入 Fact Store，永不直接进入 System Prompt。

## 拒绝方案

- 默认启用无 Key 搜索抓取：稳定性、服务条款与验收可复现性不足。
- 仅按品牌声誉指定 Provider：缺少中国网络和中文官方来源质量证据。
- 未知许可证图片自动进入 PPT：不能满足可追溯和风险提示要求。

## 后果与回滚触发

首个纵向切片可在离线/手动 URL 模式工作。若候选在中国网络 P95、错误率、中文相关性或条款上不合格，
保留统一契约并替换适配器，无需修改 Agent 状态和 Fact Store。
