# M0.1 Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the M0 evidence, SSRF, PowerPoint recovery, and public-review gaps so the automated gate is trustworthy and only human visual acceptance remains.

**Architecture:** Probe evidence is bound to current source through deterministic fingerprints and policy-based validation. Network fetching uses a DNS-pinned connector that preserves HTTPS SNI/hostname verification. PowerPoint rendering adds an idempotency journal, temporary export validation, atomic publication, and parent-side cleanup on every failure path.

**Tech Stack:** Python 3.10.20, Pydantic 2.13.4, standard-library `http.client`/`ssl`, HTTPX test transports where appropriate, pywin32 311, psutil 7.1.3, pytest 9.0.2.

## Global Constraints

- Project runtime remains `>=3.10,<3.13`; the local reproducibility environment is conda `AI`, Python 3.10.20.
- Microsoft PowerPoint integration remains Windows 11 + PowerPoint x64 and requires a clean environment with no pre-existing `POWERPNT.EXE`.
- Runtime artifacts stay under ignored `artifacts/`; only sanitized evidence is committed under `docs/evidence/m0/`.
- Secrets, absolute user paths, raw model responses, temporary paths, and API keys must never enter committed evidence.
- Networking fails closed unless every connection uses the exact public IP set validated for that redirect hop.
- Every task is implemented test-first and ends in a separate commit.
